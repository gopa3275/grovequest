## Overview

GroveQuest is a web-based platform concept designed to help users discover their strengths, interests, personality traits, and life goals through interactive quizzes and self-analysis activities.

The project combines ideas inspired by MBTI and Ikigai frameworks to encourage personal growth and self-discovery.

## Platform Used

This project was developed using Bubble.io for rapid MVP prototyping and interface design.

## Features

- Interactive quiz system
- Personality exploration
- Goal discovery concepts
- User-friendly interface
- Self-analysis approach

## Purpose of the Project

The goal of GroveQuest is to create an engaging platform where users can better understand themselves through structured assessments and guided experiences.
